Cloud Computing

  • Unit- 1.0: Introduction to Cloud Computing (7 hrs)
    • 1.1 Importance, characteristics, pros and cons of Cloud Computing; migrating into the Cloud; seven-step model of migration; trends in computing
    • 1.2 Cloud Service Models: SaaS, PaaS, IaaS, Storage
    • 1.3 Cloud Architecture: logical architecture, holistic reference model, system architecture, deployment models
  • Unit- 2.0: Data Storage and Cloud Computing (7 hrs)
    • 2.1 Enterprise data storage: DAS, SAN, NAS; data storage management; file system; cloud data stores; using grids for data storage
    • 2.2 Cloud Storage: data management, provisioning cloud storage, data intensive technologies
    • 2.3 Cloud storage from LANs to WANs: cloud characteristics, distributed data storage
  • Unit- 3.0: Virtualization in Cloud Computing (7 hrs)
    • 3.1 Definition, adopting virtualization, types, architecture and software, virtual clustering, applications, pitfalls
    • 3.2 Grid, Cloud and Virtualization: virtualization in grid and cloud; virtualization and cloud security
    • 3.3 Anatomy of cloud infrastructure; virtual infrastructures; CPU, network and storage virtualization
  • Unit- 4.0: Cloud Platforms (7 hrs)
    • 4.1 Amazon Web Services: components, Simple DB, EC2, Amazon storage system, DynamoDB
    • 4.2 Microsoft Cloud Services: Azure core concepts, SQL Azure, Windows Azure Platform Appliance
  • Unit- 5.0: Cloud Computing Applications (7 hrs)
    • 5.1 Healthcare: ECG analysis in the cloud; Biology: protein structure prediction; Geosciences: satellite image processing
    • 5.2 Business and consumer applications: CRM and ERP, social networking
    • 5.3 Google Cloud Application: Google App Engine; overview of OpenStack architecture
  • Unit- 6.0: Security in Cloud Computing (7 hrs)
    • 6.1 Risks in Cloud: risk management, enterprise-wide risk management, types of risks
    • 6.2 Data security in cloud: issues, challenges, advantages, disadvantages, cloud digital persona, content level security
    • 6.3 Cloud security services: confidentiality, integrity, availability; authorization challenges; secure cloud software requirements and testing

Principles of Management
